# Dungeon Master's Hub

Приложение для управления DnD 5e кампаниями, создания персонажей и работы со справочниками.

## Технологии

- HTML5
- SASS
- Vanilla JavaScript
- localStorage для хранения данных

## Установка и запуск

### Требования

- Node.js и npm (для компиляции SASS)
- Или любой SASS компилятор

### Установка зависимостей

```bash
npm install
```

### Компиляция SASS

```bash
npm run sass
```

Или используйте watch режим для автоматической компиляции:

```bash
npm run sass:watch
```

### Запуск приложения

Откройте `index.html` в браузере или используйте локальный сервер:

```bash
npx http-server
```

## Первый запуск

При первом запуске приложение автоматически загрузит данные из `src/data/DB.json` в localStorage.

Для доступа к админ панели создайте пользователя с ролью `admin` через консоль браузера или измените роль существующего пользователя в localStorage.

## Деплой на GitHub Pages

Проект настроен для автоматического деплоя на GitHub Pages через GitHub Actions.

### Настройка GitHub Pages

1. Перейдите в настройки репозитория на GitHub
2. Перейдите в раздел "Pages" в боковом меню
3. В разделе "Source" выберите "GitHub Actions"
4. Сохраните изменения

### Автоматический деплой

После настройки GitHub Pages, каждый push в ветку `main` или `master` автоматически:
- Установит зависимости
- Соберет проект (скомпилирует SASS)
- Задеплоит на GitHub Pages

Workflow также можно запустить вручную через вкладку "Actions" в репозитории.

### Структура деплоя

На GitHub Pages будут загружены следующие файлы:
- `index.html`
- `dist/css/main.css` (скомпилированные стили)
- `src/js/` (все JavaScript файлы)
- `src/data/DB.json`
- `src/img/` (все изображения)
- `src/fonts/` (шрифты)

### Проверка деплоя

После успешного деплоя ваше приложение будет доступно по адресу:
```
https://[ваш-username].github.io/[название-репозитория]/
```
