# Доступ к административной панели

## Учетные данные администратора

Для входа в административную панель используйте следующие данные:

- **Email:** `admin@dndhub.com`
- **Пароль:** `admin123`

## Как войти в аккаунт администратора

1. Откройте приложение в браузере
2. Нажмите на иконку пользователя в правом верхнем углу (или нажмите на любую защищенную ссылку)
3. В модальном окне авторизации введите:
   - Email: `admin@dndhub.com`
   - Пароль: `admin123`
4. Нажмите кнопку "Войти"
5. После успешного входа вы будете перенаправлены на главную страницу
6. Для доступа к административной панели перейдите по адресу: `#admin` (или используйте прямую ссылку в навигации, если она есть)

## Возможности администратора

Администратор имеет доступ к следующим функциям:

### Управление пользователями
- Просмотр списка всех зарегистрированных пользователей
- Просмотр информации о пользователях (имя, email, дата регистрации)
- Удаление пользователей (с осторожностью!)

### Управление персонажами
- Просмотр всех созданных персонажей
- Просмотр детальной информации о персонажах
- Удаление персонажей

### Управление комнатами
- Просмотр всех игровых комнат
- Просмотр информации о комнатах (участники, настройки)
- Удаление комнат

### Экспорт и импорт данных
- Экспорт всех данных приложения в JSON файл
- Импорт данных из JSON файла (с заменой текущих данных)

## Безопасность

⚠️ **Важно:** 
- Административный аккаунт создается автоматически при первой загрузке приложения
- Пароль хранится в localStorage в захешированном виде
- В продакшене рекомендуется использовать более безопасные методы хранения паролей (bcrypt)
- Не делитесь учетными данными администратора с другими пользователями

## Создание дополнительных администраторов

Для создания дополнительных администраторов:

1. Войдите в систему как администратор
2. Откройте консоль браузера (F12)
3. Выполните следующий код:

```javascript
// Получаем базу данных
const db = window.app.db;
const auth = window.app.auth;

// Создаем нового администратора
const newAdmin = db.createUser({
    email: 'newadmin@dndhub.com',
    password: auth.hashPassword('securepassword123'),
    name: 'Новый Администратор',
    role: 'admin',
    createdAt: new Date().toISOString()
});

console.log('Новый администратор создан:', newAdmin);
```

## Сброс пароля администратора

Если вы забыли пароль администратора:

1. Откройте консоль браузера (F12)
2. Выполните следующий код для сброса пароля:

```javascript
// Получаем базу данных
const db = window.app.db;
const auth = window.app.auth;

// Находим администратора
const admin = db.getUserByEmail('admin@dndhub.com');
if (admin) {
    // Устанавливаем новый пароль
    admin.password = auth.hashPassword('newpassword123');
    db.updateUser(admin.id, { password: admin.password });
    console.log('Пароль администратора сброшен. Новый пароль: newpassword123');
} else {
    console.log('Администратор не найден');
}
```

## Технические детали

- Администратор определяется по полю `role: 'admin'` в объекте пользователя
- Проверка прав администратора выполняется через метод `auth.isAdmin()`
- Все административные функции защищены проверкой прав доступа
- При попытке доступа к админ-панели без прав администратора отображается сообщение об ошибке
