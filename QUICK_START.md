# Быстрый старт

## Компиляция SASS

```bash
npm install
npm run sass
```

## Доступ к админ панели

См. файл `ADMIN_ACCESS.md` для подробных инструкций.

**Быстрый способ:**
1. Откройте консоль браузера (F12)
2. Выполните код из `ADMIN_ACCESS.md` (Способ 1)
3. Войдите: email `admin@dndhub.com`, пароль `admin123`
4. Перейдите на `#admin`

## Основные функции

### Главная страница
- Слайдер с тремя секциями
- Информационные блоки о платформе
- Футер с навигацией

### Создание персонажа
- Автоматическое распределение характеристик при выборе класса
- 4 шага: Раса → Класс → Характеристики → Снаряжение
- Валидация всех полей

### Комнаты
- Создание игровых комнат
- Модальные окна с подробной информацией
- Чат и бросок кубов

### Справочник
- Sidebar с навигацией
- Умный поиск с автопредложением
- Модальные окна для деталей
- Карточки с автоматической высотой по изображениям
