# Инструкция по деплою на GitHub Pages

## Автоматический деплой через GitHub Actions

Проект настроен для автоматического деплоя на GitHub Pages. После настройки каждый push в ветку `main` или `master` автоматически задеплоит проект.

## Шаги для настройки

### 1. Создайте репозиторий на GitHub

Если у вас еще нет репозитория:
1. Перейдите на [GitHub](https://github.com)
2. Создайте новый репозиторий
3. Загрузите код в репозиторий:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ-USERNAME/НАЗВАНИЕ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

### 2. Включите GitHub Pages

1. Перейдите в настройки репозитория (Settings)
2. В боковом меню выберите "Pages"
3. В разделе "Source" выберите **"GitHub Actions"**
4. Сохраните изменения

### 3. Проверьте workflow

1. Перейдите во вкладку "Actions" в репозитории
2. После первого push вы должны увидеть запущенный workflow "Deploy to GitHub Pages"
3. Дождитесь завершения (обычно 1-2 минуты)

### 4. Доступ к приложению

После успешного деплоя ваше приложение будет доступно по адресу:
```
https://ВАШ-USERNAME.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/
```

## Ручной запуск деплоя

Вы также можете запустить деплой вручную:
1. Перейдите во вкладку "Actions"
2. Выберите workflow "Deploy to GitHub Pages"
3. Нажмите "Run workflow"
4. Выберите ветку и нажмите "Run workflow"

## Что происходит при деплое

1. **Checkout** - клонирование репозитория
2. **Setup Node.js** - установка Node.js 18
3. **Install dependencies** - установка npm зависимостей
4. **Build** - компиляция SASS в CSS (`npm run build`)
5. **Upload artifact** - загрузка файлов для деплоя:
   - `index.html`
   - `dist/css/main.css` (скомпилированные стили)
   - `src/js/` (все JavaScript файлы)
   - `src/data/DB.json`
   - `src/img/` (изображения)
   - `src/fonts/` (шрифты)
   - `src/icons/` (иконки)
6. **Deploy** - публикация на GitHub Pages

## Устранение проблем

### Workflow не запускается

- Убедитесь, что вы выбрали "GitHub Actions" в настройках Pages
- Проверьте, что файл `.github/workflows/deploy.yml` существует в репозитории

### Ошибка при сборке

- Проверьте, что `package.json` содержит скрипт `build`
- Убедитесь, что все зависимости указаны в `package.json`

### Файлы не загружаются

- Проверьте, что файлы не исключены в `.gitignore`
- Убедитесь, что `dist/` папка компилируется правильно

### Приложение не работает на GitHub Pages

- Проверьте консоль браузера на наличие ошибок
- Убедитесь, что все пути к файлам относительные (не абсолютные)
- Проверьте, что все необходимые файлы загружены

## Локальная проверка перед деплоем

Перед деплоем рекомендуется проверить проект локально:

```bash
# Установите зависимости
npm install

# Соберите проект
npm run build

# Запустите локальный сервер
npx http-server
```

Откройте `http://localhost:8080` в браузере и проверьте, что все работает корректно.
